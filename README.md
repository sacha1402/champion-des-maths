# champion-des-maths
Ce projet est un mini-jeu éducatif en langage **C** permettant de réviser les fondamentaux des mathématiques (niveau CM1). Il contient plusieurs activités interactives comme des calculs, des conversions, et une gestion de score.

---

##  Fonctionnalités

-  **Addition**,  **Soustraction**,  **Multiplication**,  **Division exacte**
-  Lecture et écriture de grands nombres (en lettres et en chiffres)
-  Conversion de durée (heures/minutes)
-  Tables de multiplication (affichage et exercices)
-  Système de score avec sauvegarde automatique dans un fichier texte

---

##  Installation

###  Prérequis

- Un environnement Linux/Mac ou Windows avec MinGW ou WSL
- Un compilateur C comme `gcc`
